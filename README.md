Steps to Follow:
Download or clone the repository.
Run pip install -r requirements.txt to install dependencies.
Create a TrainingImage folder in the project directory.
Update paths in attendance.py and automaticAttendance.py as needed.
Run attendance.py.

Register your face by clicking "Register New Student" and entering your ID and name.
Capture images (up to 50) using the "Take Image" button.
Train the model with the "Train Image" button.
Use "Automatic Attendance" to mark attendance by recognizing faces.
View attendance records in .csv format by clicking "View Attendance."
